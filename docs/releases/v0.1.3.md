# CasePanel v0.1.3 — Windows preview

This preview adds Home Assistant shortcuts, navigation and game FPS, and configurable dashboard alerts to the Windows 11 x64 panel.

## Changes

- Persistent Spanish navigation: Resumen, Accesos and Ajustes. Gráficas remains reserved and disabled.
- Home Assistant controls for toggles, scripts/scenes and read-only sensors, with pagination, optional confirmation, immediate feedback and rollback on failed requests.
- Reloadable Home Assistant configuration in `config.toml` beside `profile.json`, or at a path selected by `--ha-config`. The package includes `config.example.toml` with an empty token; real credentials are not included.
- PresentMon 2.3.1 game FPS and mean frame time, with bounded capture history and recovery.
- Configurable dashboard colors, thresholds, critical borders, network traffic, optional AI reset timers and footer modes under Ajustes → Resumen.
- Existing widget layouts and bindings are preserved. Footer migration only uses an unoccupied bottom area.

## Downloads and installation

- **CasePanel-0.1.3-windows-x64.zip**: complete package with the application, PresentMon, setup scripts, verified official PawnIO installer, documentation, licenses and corresponding source.
- **sensorpanel.exe**: application alone, for manual use. FPS capture also requires the packaged PresentMon files; low-level readings require PawnIO and GPU readings require the NVIDIA driver.
- **CasePanel-0.1.3-source.zip**: corresponding application and module source.
- **SHA256SUMS.txt**: checksums for the downloads.

Extract the complete ZIP and run `scripts\Install.ps1` from an administrator PowerShell. For an existing installation, use `scripts\Update-Installed.ps1` as described in the README. The application executable is unsigned; the bundled PawnIO installer is separately signed and verified during packaging.

## Validation and preview limitations

All 46 unit tests passed locally, including Home Assistant loopback HTTP authentication, redirects, timeout, polling and interaction feedback. Native UI validation with a simulated Home Assistant server is documented in `docs/VALIDATION.md`; no real Home Assistant devices or credentials were used.

Hardware validation remains limited to the configuration documented in the README. Reboot, suspend/resume, display reconnection and sustained workload checks remain outstanding. Earlier resource measurements do not cover a configured Home Assistant worker. The previously reported Fortnite loss-of-clicks incident remains unresolved; this release does not claim a fix.

AI usage widgets require a separate producer. Personal credentials and producers are not included. Home Assistant controls require your own URL, token and entity configuration.
