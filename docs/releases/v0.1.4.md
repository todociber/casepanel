# CasePanel v0.1.4 — Windows preview

The Gráficas tab now includes **Ya es paja**, a configurable workday countdown with a completion ring and a timeline showing the elapsed and remaining parts of the day.

## Changes

- Second-by-second time until leaving work, percentage completed, local clock and a timeline that follows the configured start and end times.
- **Ajustes → Jornada** lets you change the meter title, enable any weekday and set each day's entry/exit time in `HH:MM`, including minutes. Defaults remain Monday–Thursday 08:00–18:00 and Friday 08:00–17:00.
- Settings preview immediately when valid. **Save** persists them in the profile; closing the editor allows changes to be discarded. Existing profiles receive the original schedule automatically.
- Before work, the meter shows the time until entry and the full shift remaining. At closing it displays **¡Ya es paja!**. Days off show the next configured working day; disabling all days shows an explicit rest state.
- Local updates now record the installed version correctly in installation metadata.

## Downloads and installation

- **CasePanel-0.1.4-windows-x64.zip**: complete Windows package with setup scripts, dependencies, licenses, documentation and corresponding source.
- **sensorpanel.exe**: application alone; this is not an installer. FPS needs the packaged PresentMon files; hardware readings still require the relevant drivers.
- **CasePanel-0.1.4-source.zip**: corresponding application and module source.
- **SHA256SUMS.txt**: checksums for the downloads.

Extract the complete ZIP. For a new installation, run `scripts\Install.ps1` from administrator PowerShell. For an existing installation, run `scripts\Update-Installed.ps1`; it backs up the existing files and profile and restarts the previously running panel/collector tasks. The application executable remains unsigned.

## Scope and limitations

Schedules use the computer's local timezone and a single interval within the same calendar day. Overnight shifts, breaks and holidays are not deducted. No extra timer, network service or continuous animation is added for the meter.

Hardware coverage and outstanding validation remain documented in the README and `docs/VALIDATION.md`. Existing preview limitations, including the unresolved Fortnite loss-of-clicks report, still apply. This release does not claim a fix for that incident or fresh long-running resource benchmarks.
