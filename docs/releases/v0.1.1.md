# CasePanel v0.1.1 — Windows preview

First downloadable preview for Windows 11 x64, with an English interface, default profile, documentation, and setup messages.

## Downloads

- **CasePanel-0.1.1-windows-x64.zip**: recommended complete package, including the application, setup scripts, official PawnIO installer, licenses, documentation, and source.
- **sensorpanel.exe**: the application alone, for manual use. This is not an installer. Low-level readings still require PawnIO and GPU readings require the NVIDIA driver.
- **CasePanel-0.1.1-source.zip**: corresponding application and module source for this build.
- **SHA256SUMS.txt**: checksums for the downloadable files.

Extract the complete ZIP and run `scripts\Install.ps1` from an administrator PowerShell to install and configure logon startup. CasePanel's executable is currently unsigned. The bundled PawnIO installer is separately signed and verified by hash and Authenticode during packaging.

## Included

- Native Win32/Direct2D/DirectWrite panel, without a browser runtime.
- Basic visual editor and versioned JSON profiles.
- Separate hardware collector, bounded recovery, and manual updates.
- Initial support validated on Ryzen 9 9900X, RTX 5080, and X870 AORUS ELITE WIFI7.
- English application labels, new default profiles, diagnostics, setup scripts, and public documentation. Existing custom profile text is preserved.

## Preview limitations

Hardware support is deliberately narrow. Three reboot checks, suspend/resume, display reconnection, sustained GPU workloads, and broader hardware validation remain outstanding. Earlier resource measurements are documented in `docs/VALIDATION.md`; they are not fresh benchmarks of this release.

A loss-of-clicks incident during Fortnite remains unresolved. It also persisted with both CasePanel processes closed and recovered after Ctrl+Alt+Delete followed by Escape. This release does not claim a fix or identify a responsible component.

AI usage widgets need a separate producer; credentials and the personal producer used during validation are not included.
